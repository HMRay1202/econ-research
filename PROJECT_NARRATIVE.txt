Econ Research: Project Overview

Purpose
Econ Research is a local-first economics-paper workspace. It preserves PDFs and organizes their content into traceable passages, research cards and single-paper deep reads.
Local-first does not mean fully offline: parsing and retrieval are local; card generation and deep reads send titles, source chunks and instructions to the configured OpenAI API and may incur charges.

Daily workflow
Import a PDF, follow parsing/formula progress, read cards, inspect source passages and the original PDF, then request a focused deep read when useful.
Reparse when extraction needs improvement. It neither changes the original PDF nor rewrites existing card text. Request a separate card generation only after reviewing the new source.
Formula recognition is best-effort. Rejected content retains a reviewable fallback; it is not verified mathematics.

Scope
The current project is a single-machine, single-database workspace centered on individual papers. The PDF remains authoritative and LLM output is derived material.
Cloud deployment, multi-user accounts, vector databases, cross-paper comparison, Zotero integration and a general multi-provider framework are outside the implemented scope.
Phase 1 functionality is delivered; native platform validation, reliability and difficult-document quality remain ongoing work.

Architecture principles
The browser uses documented HTTP APIs. FastAPI and CLI share ResearchService; Parser handles extraction, ResearchLLM isolates generation, and SQLiteRepository owns persistence.
Windows GPU operation separates Torch and Paddle into different processes to avoid native-library conflicts. It does not introduce another business service.
